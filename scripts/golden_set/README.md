# Golden evaluation set

Fixed, hand-verified reference documents used to detect OCR regressions:

- `make eval` runs the configured engine over every sample and reports CER +
  table-cell F1 against `expected.md`.
- The trainer's promotion gate re-runs candidates over this set — a fine-tuned
  model that regresses here is rejected even if it improved on the tenant's
  own corrections.

## Layout

```
golden_set/
└── sample-001-invoice/
    ├── input.pdf      # the scanned/generated source document
    └── expected.md    # hand-verified markdown ground truth
```

## Growing the set (target ~20 documents)

Add real-world variety, one directory per document:
- printed invoices / quotations / tax forms (JA + mixed EN item codes)
- handwritten memos and filled-in forms
- a vertical-text (縦書き) business letter — regression-guards reading order
- a multi-page PDF and at least one skewed/low-quality scan

Never edit an existing sample's `expected.md` to make a model pass — fix the
model. New client-specific golden documents belong in per-tenant sets, not here.

`sample-001-invoice` is generated by `scripts/generate_golden_samples.py` so
the repo stays reproducible without committing binaries from unknown sources.
